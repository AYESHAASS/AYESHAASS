### 📌 Featured Projects

**[Multi-Agent Clinical Decision Support System](https://github.com/AYESHAASS/Clinical-MultiAgent-CDSS)** (*Google x Kaggle AI Agents Capstone*)
4-agent clinical pipeline (Validator, Risk Predictor, Guideline RAG, Clinical Auditor) orchestrated with Google ADK. Wraps an XGBoost ensemble as an MCP Server tool and cross-checks predictions against ADA 2023 / PES 2022 guidelines.
🔗 [Live demo](https://huggingface.co/spaces/Ayeshaaaa17/Clinical-MultiAgent-CDSS)

**[Agentic Clinical Decision Support System](https://github.com/AYESHAASS/Agentic-AI-for-Clinical-Decision-Support-System)** (*Cotiviti Intern Assessment*)
3-layer agentic pipeline: XGBoost + Random Forest ensemble (76%+ accuracy), SHAP explainability, and a Llama-3.3-70B reasoning agent grounded via RAG in ADA 2023 guidelines for auditable, citable outputs.

**[Medical RAG Assistant](https://github.com/AYESHAASS/Medical-RAG-Assistant)**
Multi-document RAG system with LangChain, FAISS, and Llama-3.3-70B. Recursive semantic chunking, 384-dim HuggingFace embeddings, and an anti-hallucination framework with source citations.
🔗 [Live demo](https://ayeshaaaa17-rag-medical-assistant.hf.space/)

**[Diabetes Risk Prediction API](https://github.com/AYESHAASS/diabetes-fastapi-service)**
XGBoost + Random Forest voting ensemble achieving 92% accuracy and 0.88 F1-score, served via FastAPI, containerized with Docker.
🔗 [Live demo](https://ayeshaaaa17-diabetes-prediction-api.hf.space/)
